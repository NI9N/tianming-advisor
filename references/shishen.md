# 十神解读（shishen.md）

> 定位：把八字排盘输出的「十神」翻译成决策语言。这是知识层的核心查询表。
> 读取顺序：先看 `bazi.dayMaster`（日主天干）→ 再看 `bazi.shiShen`（四柱十神）→ 用本表解读。
> 重要前提：**十神本身没有绝对吉凶**。吉凶取决于它是否「喜用」（对日主是补益还是耗泄）、是否成格、以及组合。判断前先看 `bazi.enrichment.旺衰` 与 `bazi.enrichment.格局`。

---

## 一、十神是什么

十神 = 以日主（出生日的天干）为「我」，与命局中其它干支之间五行生克关系的 10 个代号。同一五行关系分「同性（阴阳相同）」与「异性（阴阳相异）」两类。

| 与我的五行关系 | 同性 → 十神 | 异性 → 十神 |
|------|-----------|-----------|
| 与我相同五行 | **比肩** | **劫财** |
| 我生之五行（我泄气） | **食神** | **伤官** |
| 我克之五行（我耗力） | **偏财** | **正财** |
| 克我之五行（克我者） | **七杀** | **正官** |
| 生我之五行（生我者） | **偏印** | **正印** |

> 例：日主为「癸」（阴水）。甲木为伤官、戊土为正官、己土为七杀、丁火为偏财。十神一律以命局日主为「我」；具体命局的四柱十神分布由 `scripts/chart.js` 运行时输出（`bazi.shiShen`）。

## 二、十个十神详解

### 1. 比肩（同我·同性）
- **正面**：独立自主、自强、重义气、平辈互助、竞争意识、脚踏实地、说到做到。
- **负面**：固执、自我、好胜、不肯低头、易被朋友分利。
- **性格倾向**：意志坚定，独立不依赖，有主见，是「自己的力」的代表。
- **事业**：适合独立深耕、专业路线；**财运**：靠自己赚，稳步积累；**人际**：平辈兄弟朋友，竞争与合作并存，慎合伙分利。

### 2. 劫财（同我·异性）
- **正面**：行动力强、反应快、社交活跃、敢冒险、有江湖义气。
- **负面**：冲动、好斗、破财、欲望强、见利易争、财来财去。
- **性格倾向**：外向热血，不服输，敢抢敢拼。
- **事业**：适合冲锋型、市场开拓、竞争性行业；**财运**：财如潮水，注意被「劫」（合伙纠纷、破财漏财）；**人际**：朋友多，需防损友与利益冲突。

### 3. 食神（我生·同性）
- **正面**：温和有才、口福、乐观、审美与创造、乐于分享、情绪稳定、享受生活。
- **负面**：空想、懒散、自我满足、过度安逸、想得多做得少。
- **性格倾向**：温和有才气，让人舒服，是「才艺」与「口才」的代表。
- **事业**：技术/艺术/创意/餐饮/教育；**财运**：才华生财、细水长流（食神生财）；**人际**：人缘好，包容温和。

### 4. 伤官（我生·异性）
- **正面**：才华横溢、表达犀利、反叛创新、不服权威、思维敏捷、追求卓越。
- **负面**：恃才傲物、言语伤人、冲动、爱出风头、不甘平凡而焦虑。
- **性格倾向**：聪明张扬、有锋芒，是「才华的表达欲」的代表。
- **事业**：创意/媒体/技术/自由职业；**财运**：技艺生财但起伏大；**人际**：爱憎分明，易起口舌，需收敛锋芒。

### 5. 正财（我克·异性）
- **正面**：勤俭务实、稳定收入、珍惜所得、责任感、脚踏实地、重承诺。
- **负面**：过于看重金钱、吝啬、保守、小富即安、风险厌恶。
- **性格倾向**：踏实可靠、会理财，是「稳赚的钱」的代表。
- **事业**：稳定职业、管理、会计、经营；**财运**：工资/正财细水长流；**人际**：值得信赖，重契约。

### 6. 偏财（我克·同性）
- **正面**：大方、机会嗅觉、市场意识、灵活、会赚外快、人脉广、敢投入。
- **负面**：花钱大手大脚、投机心态、见异思迁、不稳定。
- **性格倾向**：外向大方、有商业头脑，是「机会的钱/市场」的代表。
- **事业**：市场/销售/投资/副业/经商；**财运**：大财、偏财、投资回报，有进有出；**人际**：广结善缘，长于应酬。

### 7. 正官（克我·异性）
- **正面**：责任感、自律、守规矩、正直、名声、被信任、管理能力。
- **负面**：压力大、过于守旧、畏惧权威、自我束缚、循规蹈矩。
- **性格倾向**：自律负责、有原则、靠谱，是「规则与名分」的代表。
- **事业**：管理/体制内/规范行业，适合被委以重任；**财运**：财源稳定（官可护财）；**人际**：得体，上级缘好。

### 8. 七杀（克我·同性）
- **正面**：魄力、决断、抗压、竞争力强、权威气场、越挫越勇、挑战精神。
- **负面**：暴躁、偏激、压力爆表、树敌、铤而走险。
- **性格倾向**：强势、有攻击性、天生抗压，是「压力与权力」的代表。
- **事业**：管理/军警/高压岗位，险中求成；**财运**：险中求财、大起大落；**人际**：有威慑力，需软硬兼施。
- **关键**：七杀有制（食神制杀/印化杀）则为将才、贵人；无制则易惹祸、透支。

### 9. 偏印（生我·同性）
- **正面**：独特思维、洞察力、悟性、逆向思维、技术/玄学天赋、专注、孤独地钻研。
- **负面**：孤僻、多疑、想太多、钻牛角尖、冷淡、不合群。
- **性格倾向**：内敛思考型、有个性，是「独特心智」的代表。
- **事业**：研究/技术/玄学/心理/冷门专业；**财运**：偏门之财，需靠专业变现；**人际**：交心者少，独来独往。

### 10. 正印（生我·异性）
- **正面**：学识、学历、长辈庇佑、贵人、文化、内心安稳、宽容、口碑。
- **负面**：依赖心、安逸、缺乏进取、慢节奏、要面子。
- **性格倾向**：好学温和、有书卷气、顾家，是「学习与靠山」的代表。
- **事业**：教育/文化/研究/体制内；**财运**：财来得稳（靠专业与名望）；**人际**：长辈缘好，贵人扶持。

## 三、十神组合（高价值解读）

单个十神是原料，**组合才决定命局走向**。解读优先看组合：

| 组合 | 含义 | 决策提示 |
|------|------|---------|
| 食伤生财 | 才华/创意 → 变现通路顺畅 | 用技能与创意赚钱是正路，适合做内容/产品/技艺 |
| 伤官配印 | 才华有约束、有靠山 | 放开发挥创造力，同时守住根基（学历/背书/长辈支持） |
| 杀印相生 | 压力被转化为资源/权力 | 逆境遇贵人，把高压岗位/难题变成晋升阶梯 |
| 官杀混杂 | 目标分散、压力来源多 | 需要定主次、抓主线，避免同时接太多框架 |
| 身强财旺 | 担得住财 | 能赚能守，适合投资与经营 |
| 身弱财多 | 财多身弱，求财反为财所累 | 先补身（借印/比之力）再求财，别硬扛大机会 |
| 比劫夺财 | 竞争分利 | 慎合伙，财不外露，防朋友借钱/抢机会 |

**身强身弱怎么用**（结合 `bazi.enrichment.旺衰`）：
- 身旺（日主力量足）→ 喜财（我克）、官杀（克我）、食伤（我生）来「泄耗」，让能量有出口。
- 身弱（日主力量不足）→ 喜印（生我）、比劫（同我）来「生扶」，先站稳再发展。
- 决策翻译：身弱时期少揽大项目、少单挑硬仗，多借助团队、靠山、学习补强；身旺时期适合主动出击、扩张、担责。

## 四、十神 × MBTI / 霍兰德 映射

用于把传统命理术语翻译成用户能感知的现代人格语言。**用户人格基线（mbti / holland / drivers）从 `config.yaml` 的 `personality` 读取**，运行时用实际值替换解读。

| 十神 | 现代人格类比 | 说明 |
|------|-------------|------|
| 食神 / 伤官 | **霍兰德 A（艺术创造表达）** | 才华、表达、创作、审美 |
| 正官 / 七杀 | **框架与规则（J 偏好 / 传统管理型 E/C）** | 结构、责任、计划、规则感 |
| 偏财 | **市场机会（霍兰德 E 企业）** | 机会嗅觉、人脉、交易、回报 |
| 正财 | **常规稳定（霍兰德 C / 实感 S）** | 踏实、可预期、细水长流 |
| 比肩 / 劫财 | **现实动手（霍兰德 R）** | 独立实干、竞争、身体力行 |
| 正印 | **学习研究（霍兰德 I）** | 求学、积累、贵人、系统知识 |
| 偏印 | **深度洞察 / 直觉（霍兰德 I + N 直觉）** | 逆向思维、专精、玄学/技术悟性 |

> 对用户人格基线的特别提示（从 `config.yaml` 的 `personality.mbti / traits` 读取）：按用户 mbti 的 J 偏好判断是否需要结构与规则（避免散漫焦虑）；按 holland 的 E/S/A 判断表达与利他倾向；按 drivers 中的成长学习驱动判断印的重要性。当命局「印食」旺时，接近用户舒适区；「官杀」旺时，是外界在加框架、施压。

## 五、决策用法（LLM 调用指引）

1. **看整体性格底色**：数一数 `bazi.shiShen` 四柱中哪个十神最多/最集中，那就是命局主色调（配合 `enrichment.格局` 确认）。
2. **判断喜忌**：先看 `enrichment.旺衰.verdict`（偏强/偏弱）再定喜用，避免把「强十神」直接当吉、把「弱十神」直接当凶。
3. **映射到决策维度**：
   - 事业方向 → 看食伤（创造）、正印（研究）、正官（管理）哪个最能承接用户驱动（从 `config.yaml` 的 `personality.drivers` 读取）。
   - 财运 / 求财时机 → 看财（正财/偏财）是否当令、是否喜用；偏财旺且喜用 → 适合市场/合作/副业。
   - 人际 / 合伙 → 比劫多则慎合伙，正官旺则适合被信任的正式角色。
4. **落到用户的现代语言**：用「霍兰德类型 + MBTI J 的结构需求」来回译（用户类型从 config.yaml 读取），让建议可执行，而不是停留在命理术语。
