# 神煞解读（shensha.md）

> 定位：把引擎 `enrichment.神煞` 输出的神煞翻译成决策语言。这是知识层的补充查询表。
> 读取顺序：先看 `enrichment.神煞` 数组（引擎已算好）→ 用本表解读每个命中神煞的含义。
> 重要前提：**神煞是辅助层，不替代五行生克/格局/旺衰的主判断**。神煞吉凶要在五行喜忌的框架内解读——同一神煞，落在喜用神位置是锦上添花，落在忌神位置则凶性放大。

## 二、逐个解读（决策翻译）

### 1. 天乙贵人（吉 · 最尊贵）
- **含义**：逢凶化吉之星，遇事有人帮，临难有人解。人缘佳，易得社会地位与长辈/上级提携。
- **决策翻译**：
  - 命带天乙且落在喜用位 → 关键决策可以适度"借力"——贵人缘是你可依赖的资源，该开口时就开口
  - 落忌神位 → 贵人缘有但"帮不到点子上"，求人前先想清楚自己要什么
  - 双重天乙（年干+日干都见）→ 贵人运格外强，但别形成依赖，贵人也会累
- **注意**：天乙最忌空亡（贵人落空=想帮你的人使不上劲）

### 2. 文昌贵人（吉 · 学业/才华）
- **含义**：聪明好学、文思敏捷、利考试/创作/表达。主文笔、学术、文化类才华。
- **决策翻译**：
  - 命带文昌 → 靠"写/讲/学/创作"吃饭的路对你天然顺，考试、考证、输出类工作加分
  - 落时柱 → 才华有"传出去"的后劲，适合做内容、教学、表达型方向
  - 与食神/伤官同柱 → 才华输出加倍，但注意别恃才傲物

### 3. 驿马（中性 · 变动/远行）
- **含义**：主奔波、走动、远行、迁移。一生走动多，坐不住。
- **决策翻译**：
  - 命带驿马 → 你是"动中求财"型：出差、外派、跨地/跨界的机会对你反而有利
  - 落年月 → 早年离家、求学远行；落日时 → 中年后异地发展、经常移动
  - 决策提示：驿马年是"宜动不宜守"的年份，适合跳槽/搬家/启动新方向；但驿马逢冲是"乱动"，要看清方向再动

### 4. 桃花(咸池)（中性 · 人缘/异性缘）
- **含义**：人缘好、异性缘、艺术审美感。非吉非凶，看落位。
- **决策翻译**：
  - 落年/月柱 → 天生招人喜欢，适合需要人际/形象/审美的领域
  - 落日/时柱 → 异性缘在成年后显现，感情机会多但需辨"烂桃花"
  - 与财/官同柱 → 靠人缘吃饭（销售/公关/内容/艺术）；与劫煞/空亡同柱 → 烂桃花、感情耗损
  - 决策提示：桃花重的年份（流年遇桃花）感情波动大，重大感情决策宜缓不宜急

### 5. 华盖（中性 · 孤独/玄学/艺术）
- **含义**：主孤高、聪慧、艺术/玄学缘分、内心孤独。喜静、思想深刻。
- **决策翻译**：
  - 命带华盖 → 你天生适合"深钻研"型工作（研究/技术/玄学/艺术/写作），且往往有这方面的天赋兴趣
  - 落日/时柱 → 晚年更喜独处，社交需求低但内心世界丰富
  - 与印星同柱 → 智慧型孤独，思维有深度；与伤官同柱 → 才华横溢但恃才孤傲
  - 决策提示：华盖重的人**不适合强社交型工作**，别硬逼自己"合群"——你的优势在深度不在广度

### 6. 将星（吉 · 领导/权力）
- **含义**：掌权之星，有领导力、能服众、镇得住场面。主威望、担当。
- **决策翻译**：
  - 命带将星 → 你天生有"带队/做主"的气场，适合承担管理、牵头、拍板的位置
  - 落年/月柱 → 年轻时就有领导潜质；落日/时柱 → 中年后掌权
  - 决策提示：将星位适合"自己说了算"的路径，但将星遇冲（流年冲将星位）是权力动荡年，忌争权

### 7. 劫煞（凶 · 突发/争夺）
- **含义**：主突发变故、财物被夺、意外冲击。与"劫"相关——争财、被抢、意外。
- **决策翻译**：
  - 命带劫煞 → 财物上要防"突然被夺走"：防骗、防合作方卷款、防冲动投资
  - 落月柱（事业位）→ 事业上防突然变故：合同被毁、项目被抢、被小人算计
  - 决策提示：劫煞逢冲的年份（流年冲劫煞位）是"防劫年"——现金别外借、重要证件别乱签、大额决策三思

### 8. 孤辰（凶 · 孤独）
- **含义**：主孤僻、六亲缘淡、独立。男命尤忌（孤辰主克妻/孤独）。
- **决策翻译**：
  - 命带孤辰 → 性格深处有"习惯一个人"的部分，亲密关系里容易冷场/需要空间
  - 落月柱 → 与父母/家庭有疏离感；落日柱 → 婚姻/亲密关系需要更多独立空间
  - 决策提示：孤辰重的人，**重要决定要给自己留"独处消化"的时间**，别在情绪孤独时做冲动决定

### 9. 寡宿（凶 · 寡淡）
- **含义**：主寡淡、孤寡、与配偶/同伴缘薄。女命尤忌（寡宿主克夫/寡居）。
- **决策翻译**：
  - 与孤辰常成对出现（隔角煞）→ 独来独往、不轻易交心
  - 决策提示：寡宿重的人适合"专业型独立路线"，但感情/合伙上要主动经营，别默认对方懂你

### 10. 空亡（凶 · 落空）
- **含义**：主虚、空、不成、拖延。所落之柱对应的人生领域"使不上劲"。
- **决策翻译**：
  - 落年柱 → 祖上/早年助力空；落月柱 → 事业/父母位有空耗感；落日柱 → 配偶/自身某部分落空；落时柱 → 晚年/子女位有落空
  - 空亡逢冲 → 反而"冲空则实"（坏事变好事）；空亡遇合 → 填实（坏事变实）
  - 决策提示：空亡重的领域，**别把宝押在那里**——比如空亡在财帛位，就别赌大额投资；空亡在官禄位，就别死磕仕途
  - 关键心法：空亡是"虚位"，它提醒你**在哪投入会打水漂，就别在哪死磕**，换个地方发力

## 二·补 第二批神煞（引擎扩展后）

### 11. 太极贵人（吉 · 聪明/玄学）
- **含义**：主聪明好学、悟性高、喜钻研玄学/哲学/宗教。查法同天乙。
- **决策翻译**：命带太极 → 适合研究型/思想型路线；思维有深度，但容易"想太多"，注意落地。

### 12. 金舆（吉 · 福气/车马）
- **含义**：主福气、荫庇、坐享其成之象。禄前二辰为金舆。
- **决策翻译**：命带金舆 → 人生常有"不劳而获"的小福气（贵人提携、意外之喜）；但别把福气当本事，该努力仍要努力。

### 13. 国印贵人（吉 · 实权/印章）
- **含义**：主掌印、实权、受重用。逢之易于执掌实权。
- **决策翻译**：命带国印 → 适合承担"有实权"的位置（管人/管钱/管印章）；决策时"名分"对你重要——名正言顺的事你做得顺。

### 14. 禄神（吉 · 俸禄/食禄）
- **含义**：主俸禄、衣食、稳定收入。日禄归时尤其贵。
- **决策翻译**：命带禄神 → 有稳定饭碗的命；禄神落时柱（日禄归时）为晚年安稳。禄被冲（流年冲禄位）则当年收入波动，宜守。

### 15. 学堂（吉 · 学业/聪慧）
- **含义**：主学业、聪明、文雅。读书考试利器。
- **决策翻译**：命带学堂 → 学习能力强、适合深造/考证；学生时代成绩好，工作后适合需要持续学习的领域。

### 16. 词馆（吉 · 文采/表达）
- **含义**：主文采、口才、文章。与学堂并称"文明之象"。
- **决策翻译**：命带词馆 → 文字/口头表达是你的优势；写作、教学、演讲、内容类方向有加成。

### 17. 魁罡（中性 · 刚毅/决断）
- **含义**：日柱为庚辰/庚戌/壬辰/戊戌者。主性格刚毅、胆大、有决断力，不喜受人压制。
- **决策翻译**：魁罡命 → 果断、有魄力、天生不服管；适合"自己说了算"的路径。但魁罡性刚，容易与人硬碰硬，决策时注意留余地；魁罡逢冲（流年冲魁罡日柱）为"魁罡入狱"，当年忌冲动行事。

### 18. 月德贵人（吉 · 仁慈/解厄）
- **含义**：以月支三合局查同气阳干。主仁慈、逢凶化吉、灾祸减半。
- **决策翻译**：命带月德 → 遇险多能化解，贵人常在危难时出现；性格有善根，适合帮助他人的事业。月德遇冲则解厄之力减弱，当年谨慎。

### 19. 天德贵人（吉 · 福德/解厄）
- **含义**：以月支查。主福德深厚、逢凶化吉，与月德并称"天月二德"。
- **决策翻译**：命带天德 → 一生多遇"化险为夷"之事；天德+天乙同现为"双贵"，贵人运极强。决策时遇到难关，往往有意外转机，但仍需自己做主。

### 20. 天医（中性 · 医缘/健康）
- **含义**：主医药、健康相关缘分。
- **决策翻译**：命带天医 → 与医学/健康/养生有缘，适合健康相关行业；身体有小病小痛时较易遇到好医生。健康上注意"小病拖延"倾向，及时就医。

## 四、使用原则

1. **神煞是辅助，不替代五行主判断**——吉凶以格局/旺衰/喜忌为准绳，神煞只做加减法
2. **看落位**——同一神煞，落喜用位加分，落忌神位减分
3. **看对冲**——空亡逢冲则实、逢合则填；其他神煞逢冲力量减半
4. **看流年引动**——流年地支遇命中神煞位 = 该神煞被"引动"，当年对应事项放大
5. **性别差异**——孤辰男命更忌、寡宿女命更忌（传统说法，仅供参考）
