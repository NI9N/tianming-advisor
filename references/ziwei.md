# 紫微领域地图（ziwei.md）

> 定位：回答「**这件事落在人生哪个领域、该领域你的基本盘是什么**」——八字定大势，紫微落宫定位。
> 与八字的配合：八字回答「**时机**」（现在合不合），紫微回答「**领域**」（这事的根在哪、健不健壮）。一纵一横，两条轨互补。
> 数据来源：`node scripts/chart.js` 输出 `ziwei`（十二宫）。先用本文档末节「ziwei JSON 字段说明」读懂数据，再用本文件解读。

## 二、主星 = 根（基本盘）

紫微用「十四主星 + 辅星」描述每个领域的底层配置。**主星组合 = 这个领域的根（基本盘/慢变量）**——不管外在怎么变，你在这领域天生是哪种打法，先看清这根。

十四主星速查（用健壮性语言翻译「基本盘」）：

| 主星 | 基本盘（根） | 易过拟合的点 |
|------|-------------|-------------|
| 紫微 | 掌控与核心，天然想当基本盘 | 过拟合于「掌控感」，放不下手 |
| 天机 | 动脑策划、灵活应变 | 脑内推演过拟合，想得多动得少 |
| 太阳 | 光明付出、服务立身 | 燃烧自己过拟合，忌时耗损大 |
| 武曲 | 实干生财、执行力 | 只认功利，情绪面欠账 |
| 天同 | 平和福气、松弛感 | 安逸过拟合，动力不足 |
| 廉贞 | 权变、驾驭复杂局面 | 在人际/是非里过拟合 |
| 天府 | 库藏守成、资源稳重 | 守成过拟合，行动迟滞 |
| 太阴 | 内在滋养、细腻感知 | 情绪过拟合，内耗深 |
| 贪狼 | 欲望才艺、交际触角 | 什么都想要，样样不深耕 |
| 巨门 | 口才表达、以言立身 | 忌时口舌是非耗损 |
| 天相 | 辅佐协调、稳健可靠 | 被动过拟合，不敢自己定盘 |
| 天梁 | 荫庇贵人、清高风骨 | 好为人师，越界操心 |
| 七杀 | 攻坚破局、行动力 | 冒进过拟合，冲过头 |
| 破军 | 破旧立新、变革开创 | 破坏过拟合，立不住新盘 |

辅星速查（只看「影响根健不健壮」，不细论）：

- 左辅 / 右弼 / 天魁 / 天钺 = **贵人星** → 根周围有帮手，健壮加分
- 文昌 / 文曲 = **才艺文书** → 根在文墨、表达上有底子
- 禄存 / 天马 = **财库 / 奔波** → 资源在流动，双刃
- 火星 / 铃星 / 擎羊 / 陀罗 = **煞星** → 根上有压力毛刺，做事带痛感，但能磨出韧性
- 地空 / 地劫 = **空亡星** → 根上有「空转」风险，计划易落空，需务实落地对冲
- 红鸾 / 天喜 = **桃花喜庆** → 人际、情感面加成

**读根口诀：先看主星组合（基本盘），再看有无煞星/空星（毛刺/空转），判断这根健不健壮。**

## 三、四化 = 风/叶（引动）

四化（禄/权/科/忌）是命盘里的「动态注入」，正好对应健壮性系统的**风（环境/噪声）与叶（信号/投影）**：

| 四化 | 健壮性翻译 | 决策含义 |
|------|-----------|---------|
| **禄** | 注入资源的顺风叶 | 这领域当下被外部加持，可借势，**但别把风当根** |
| **权** | 加压与权柄的风 | 硬任务/责权压身，风在推你，接住但别硬扛成常态 |
| **科** | 名分认可的虚名叶 | 好看、有声望，但**虚名≠基本盘**，别当真收入 |
| **忌** | 该领域在过拟合（人心模式） | 付出多回报慢、内耗深，**宜退一步守根**，别在这领域加码 |

**读风口诀：忌 = 过拟合警报，禄 = 顺风信号，权/科 = 压力与虚名——都只是风/叶，不是根。**

## 四、解读三步（核心流程）

针对「这个问题」，三步走完就给结论：

1. **定位落宫**：查第一节映射表，确定主宫 + 辅宫。
2. **读根（主星）**：读主宫主星 + 辅星，判断「这领域你的基本盘是什么、健不健壮」——有煞星 → 带毛刺的根；有空星 → 易空转的根；贵人星多 → 有帮手的根。
3. **看风（四化）**：看该宫本命四化 + 流年四化，判断风是顺（禄）是逆（忌）。
4. **下结论**：动这里是**动根还是动叶**？会不会过拟合？
   - 主星健 + 无忌 → 这领域基本盘扎实，动它相对安全。
   - 主星有毛刺 + 有忌 → 这领域正在过拟合，宜守不宜攻，先修根再动叶。
   - 有禄只是风 → 可以借势，但要记住「别把风当根」，兑现要落到根上。

**和健壮性系统的关系：紫微十二宫 = 人生领域的拆解，主星 = 根，四化 = 风/叶，忌 = 过拟合警报。解读全程用「根/叶/过拟合」语言输出，不堆命理术语。**

## 五、ziwei JSON 字段说明（实测字段名，勿猜）

`node scripts/chart.js` 输出 `ziwei` 部分：

```
ziwei.wuXingJu       五行局，如 { name:'火六局', number:6 }
ziwei.yinYang        阴阳，如 '阳男'
ziwei.gongs          十二宫数组（顺序固定：命宫/兄弟/夫妻/子女/财帛/疾厄/迁移/交友/官禄/田宅/福德/父母）
  [ {
      gong:        '宫名',              // 命宫/财帛/官禄/迁移/...
      dizhi:       '宫位地支',
      tiangan:     '宫位天干',
      mainStars:   [ '主星', ... ],     // 可能为空数组
      auxStars:    [ '辅星', ... ],
      sihua:       [ { star:'星', hua:'化禄/化权/化科/化忌' }, ... ],
      daXian:      { startAge, endAge, isCurrent, daXianGongName },  // 大限（十年）
      liuNian:     [ 岁数, ... ],       // 该大限覆盖的流年岁数
      liuNianYear: 年份,                // 该宫作流年命宫的年份（对应当年命宫落此）
    }, ... ]
```

**常用取数**：
- 某宫主星 → `gongs.find(g => g.gong==='官禄').mainStars`
- 某宫四化 → 该宫 `.sihua`（取 hua 含「化忌」的看忌）
- 当前大限 → `gongs.find(g => g.daXian.isCurrent===true)`，读 `daXianGongName` + `startAge-endAge` + 该宫 `mainStars`
- 当年流年命宫 → `gongs.find(g => g.liuNianYear===当前年)`，读该宫 `gong` + `mainStars` + `sihua`

## 六、示例（通用演示数据，非真实用户）

- 假设问「该不该跳槽去外地」：落宫 = 迁移宫（主）+ 官禄宫（辅）。
- 迁移宫主星天机 + 文昌，无四化 → 基本盘 = 出门靠脑子 + 文书，根健壮、风平 → 「外出是动叶（换环境/机会），你的根撑得住，但兑现要靠官禄宫的基本盘落地」。
- 官禄宫太阳化忌 → 事业根上带忌（过拟合警报），当前事业在消耗 → 「先别在旧轨道加码，换个环境反而是退一步守根」。
- 结合八字时机给最终判断。
