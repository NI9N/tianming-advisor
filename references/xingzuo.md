# 西洋星盘解读（xingzuo.md）

> 定位：把 `node scripts/astro.js` 输出的太阳/月亮/上升星座翻译成「决策三方镜」——**太阳=我想做什么，月亮=我情绪上安不安全，上升=别人看我怎么动**。
> 数据来源：`scripts/astro.js` 输出 `{ sun, moon, rising }`，每个为 `{ sign:'金牛', longitude:43.99, signDegree:13.99 }`（黄经 + 星座内度数）。
> 本文件只写「解读规则」；具体星座值由脚本在运行时计算，不写死。

---

## 一、三方镜：三个星座各自管什么

| 星座 | 管什么 | 决策中的提问 |
|------|--------|-------------|
| **太阳星座** | 核心自我、人生方向、意志与目标 | 我**想**做什么？（方向感） |
| **月亮星座** | 内在情绪、本能反应、安全感来源 | 我情绪上**安不安全**？（情绪底座） |
| **上升星座** | 外在面具、第一印象、人生起步方向 | 别人看我怎么动？我从哪里起步？（外在路径） |

**决策运用口诀**：**太阳想走，月亮要稳，上升在敲门。**
- 一个决策至少同时过三关：太阳关（这符合我的人生方向吗）、月亮关（这让我情绪上安全吗）、上升关（外人眼中我这么做像话/顺理成章吗）。
- 三关都顺 → 高契合，可推进；太阳月亮冲突（想走但不安）→ 先解决安全感再动；太阳上升冲突（想做但跟外人期待不符）→ 先想清楚「我要不要活成别人期待的样子」。

## 二、十二星座原型速查（供运行时查任意星座）

## 三、与人格基线的映射提示（用户人格基线从 `config.yaml` 的 `personality` 读取）

- 星盘三轴给的是「天生的三股力量」，人格基线与它共振或张力，是解读的高价值点：
  - **共振点**（先讲）：上升若偏「照顾/服务」与霍兰德 S（社会服务）共振；月亮若偏「深度/掌控」与需要「意义感与掌控」的人格契合；太阳若偏「积累/实做」与霍兰德 R（现实动手）相通。（具体星座以 `astro.js` 运行时输出为准）
  - **张力点**（重点讲）：外在呈现（上升）与内在自我（太阳/月亮）不一致时，是压力也是成长空间。例：上升偏「稳健务实」而内在偏「热情表达」，构成「我想热烈冲、外在却要求我稳」的张力——决策时要把这种内外拉扯说破，避免用户内耗。
- **动荡型人格特别提示**（是否动荡型从 `config.yaml` 的 `personality.mbti` 是否带 T 判断）：月亮星座决定「情绪安全底座」。月亮落在掌控型/深度型的人格，往往用「把底牌握在自己手里」来对冲自我怀疑；月亮落在需要认可型则相反，需要外界反馈。解读建议时据此调整「给鼓励」还是「给结构」。
- **决策落地**：把三方镜落到五段式建议时，太阳→方向段，月亮→风险评估段（情绪底线），上升→执行段（外人看得见的动作）。

## 四、示例解读（演示如何套用规则，以下数值为示意，非真实数据）

已知（`scripts/astro.js` 输出）：**太阳白羊 10° / 月亮双鱼 15° / 上升天秤 5°**。仅作演示如何套用本文件规则：

- **太阳白羊** → 我**想**做什么：方向是「开创、冲出去、开创新局」。适合做需要行动力和先发优势的事，而非久拖不决。决策提问：这件事值得我第一个冲吗？
- **月亮双鱼** → 我情绪上**安不安全**：内在情绪如海，易共情易受伤，需要温柔接纳与缓冲。在情绪反复、边界模糊时最不安。决策提问：我情绪上有没有被照顾到？没有 → 先别硬扛。
- **上升天秤** → 别人看我怎么动：外在给人优雅得体、善调和的第一印象，起步方向偏「关系 / 平衡 / 协作」。外人眼中你得体可靠，适合以协作和形象起步。决策提问：外人看我这步顺理成章吗？我有没有给人可靠的形象？
- **三方合看**：太阳开创 + 月亮敏感 + 上升调和 → 决策建议应「用得体协作的姿态起步，做需要行动力但照顾情绪节奏的事」；对外圆融、对内要顾情绪，别接「伤情绪又没方向」的局。
