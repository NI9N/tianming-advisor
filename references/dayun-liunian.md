# 大运流年解读（dayun-liunian.md）

> 定位：回答「**时机**」类问题（该不该现在做 / 现在适不适合 / 什么时候动）。这把时间轴拆成「大运（十年）→ 流年（一年）→ 流月/流日（可选）」三层，用「引动」判断当下哪个主题被激活。
> 数据来源：`node scripts/chart.js` 输出 `bazi.dayun`（大运数组）与 `bazi.siZhu`（命局）。先用本文档末节的「命盘 JSON 字段说明」读懂数据，再用本文件解读。

---

## 一、时间轴三层

| 层级 | 跨度 | 看什么 | 回答什么 |
|------|------|--------|---------|
| **大运** | 十年一柱 | 人生阶段主题（该阶段的主旋律） | 我正处在什么「发展阶段」？重点该押在哪？ |
| **流年** | 一年一柱 | 当年引动哪个十神/五行 | 今年适不适合做 X？哪个领域被激活？ |
| **流月 / 流日** | 一月 / 一日 | 精确到月/日的引动（进阶） | 更细的出手时机（一般到流年足够） |

**决策优先级：大运定基调 → 流年定窗口 → 流月定出手点。** 大运不顺时，流年再好也只是局部机会；大运当令时，流年引动决定具体落在哪个领域。

---

## 二、大运：十年一变，看人生阶段主题

- **一柱大运 = 十年**。大运的天干地支构成了这十年最重要的环境背景。
- **顺排 / 逆排规则**：由「出生年天干的阴阳」+「性别」决定。
  - **阳年男、阴年女 → 顺排**（从月柱干支顺推下一柱）。
  - **阴年男、阳年女 → 逆排**（从月柱干支逆推上一柱）。
  - 阳年 = 年干为甲丙戊庚壬；阴年 = 年干为乙丁己辛癸。
- **起运年龄**：从出生日算到「下一个/上一个」节气的天数 ÷ 3（三天折一岁，一天折四个月）→ 大致推算出几岁起运（引擎已给出 `startAge` / `startYear`）。
- **怎么读**：大运天干地支各有十神（引擎已给出 `ganShiShen` / `zhiShiShen`），看这一柱哪个十神当令（力量重 / 透干），就是这十年的「主题」。
  - 例：偏财大运 → 这十年的主题是「机会 / 市场 / 求财」，适合开拓、合作、投资。
  - 例：正印大运 → 这十年「学习 / 贵人 / 积累」，适合读书、考证、跟对靠山。
  - 例：七杀大运 → 这十年「压力 / 攻坚」，适合扛硬仗、升职，但要防透支。

---

## 三、流年：每年一柱，看当年引动

- 流年 = 当年的干支（一柱管一年）。引擎已把每步大运内的流年逐列排好（`dayun[].liuNian[]`）。
- **先定年干、年支各自对应的十神**（相对日主），再结合大运看叠加效应：
  - 流年引动「偏财」→ 当年求财 / 合作 / 市场机会偏多。
  - 流年引动「正官」→ 当年职场规则、名分、责任被强调。
  - 流年引动「伤官」→ 当年表达欲强，宜输出内容 / 创作，防口舌。
- **流年是大运的「触发器」**：大运定十年大方向，流年决定今年这件事该不该动手。

---

## 四、流月 / 流日（可选深度）

- 把流年再往下拆：流月看「当月」，流日看「当天」。一般决策到流年足够，重大时机（签约、跳槽、启动大项目）才拆到流月。
- 用法：与流年同理——看当月干支引动哪个十神、与命局/大运发生什么关系。

---

## 五、「引动」概念（核心）

大运 / 流年的天干地支，与**命局四柱**（`bazi.siZhu`）之间发生**合、冲、刑、害**时，对应的十神就被「引动」——原本安静的力量被激活，事件开始显化。

| 关系 | 性质 | 决策含义 |
|------|------|---------|
| **合**（天干五合 / 地支六合、三合、拱合） | 汇聚、结合、牵绊 | 被引动的十神「成事」：合作、绑定、机会成形；也可能「贪合忘事」 |
| **冲**（六冲） | 冲突、变动、突破 | 被冲的十神「动起来」：变动、搬家、跳槽、开合；也主矛盾与震荡 |
| **刑** | 纠缠、麻烦、拖累 | 引动的是「麻烦面」：注意文书、法律、健康、人际纠缠 |
| **害**（六害） | 暗中受损、隔阂 | 引动的是「隐性损耗」：小人在暗、合作有隐患 |

**判断「被引动的是哪个十神」**：看发生合冲刑害的那个干支，相对日主是什么十神。
- 例：流年地支与原局年支相冲，且该支的十神为「正印」→ 今年正印（学习/贵人/靠山）领域被冲击，可能出现「换环境、离开旧靠山、重新学习」的变动。

**看命局内部已有关系**（引擎 `enrichment.天干关系 / 地支关系` 已列出）：命局本身就有的合冲刑害是「长期底色」，大运流年只是去「触发」它们。

## 六、决策用法：问时机时怎么用

1. **定当前大运**：看 `bazi.dayun` 中 `startYear ≤ 今年 ≤ endYear` 的那一柱，读它的 `ganShiShen` / `zhiShiShen` → 知道现阶段主旋律。
2. **看流年引动**：取当年流年的干支 → 判断其相对日主的十神 → 看它与原局/大运是否发生合冲刑害 → 判断「哪个主题被激活」。
3. **结合喜忌**：被引动的十神若是喜用 → 顺风局，可推进；若是忌神 → 逆风局，宜防守、暂缓。
4. **给出判断**：
   - 偏财当令 / 被引动 → 求财、合作、市场时机。
   - 正官当令 → 适合正式化、升职、背调、规范事务。
   - 印当令 → 学习、考证、积累、找靠山。
   - 官杀过重 → 压力期，宜减负、别硬扛。
   - 比劫被冲 → 人际变动、合伙风波，谨慎合伙。

## 七、命盘 JSON 字段说明（实测字段名，勿猜）

`node scripts/chart.js` 输出结构（顶层为 `{ bazi: {...}, ziwei: {...} }`，本 skill 只用 `bazi`）：

```
bazi.siZhu       四柱干支
  { year:{gan:'X', zhi:'Y'}, month:{...}, day:{...}, hour:{...} }
bazi.dayMaster   日主天干，如 'X'（十神都以它为「我」）
bazi.shiShen     四柱十神，如 { year:'十神', month:'十神', day:'比肩', hour:'十神' }
bazi.zhangSheng  十二长生自坐，如 { year:'长生', month:'沐浴', day:'冠带', hour:'临官' }
bazi.naYin       纳音，如 { year:'纳音', month:'纳音', day:'纳音', hour:'纳音' }
bazi.cangGan     地支藏干（查天干关系时用）
bazi.dayunStart  起运岁数（第几步起运）
bazi.dayun       大运数组（每项=十年一柱）
  [ {
      ganZhi: { gan:'X', zhi:'Y' },          // 这步大运的干支
      startAge: <起运岁数>,  startYear: <起运年>,
      endYear: <起运年+10>, endAge: <起运岁数+10>,
      ganShiShen: '十神',                       // 大运天干对应的十神
      zhiShiShen: '十神',                       // 大运地支对应的十神
      liuNian: [ { year, age, ganZhi:{gan,zhi} }, ... ]  // 这十年逐年的流年
    }, ... ]
bazi.enrichment  格局 / 旺衰等增强信息
  {
    格局:      { primary:'格局名', basis:'...', 透干:[...], confidence:'高/低', notes:[] },
    旺衰:      { verdict:'偏强/偏弱/中和', score: <数值>, confidence, breakdown:{得令,长生,得地,得势,details} },
    调候用神:   [ 'X','Y','Z' ],
    五行旺相:   { 木:'旺/相/休/囚/死', 火:'...', 土:'...', 金:'...', 水:'...' },   // 旺相休囚死
    五行统计:   { surface:{...}, withCangGan:{...}, missing:[], strongest:[...], shiShenGroups:{...} },
    天干关系:   [ { type:'天干相克/天干合', gans:['X','Y'], pillars:['年','月'] }, ... ],
    地支关系:   [ { type:'六合/三合/拱合/拱会/暗合/冲/刑/害', zhi:[...], pillars:[...], detail? }, ... ],
    自坐:       { 年:'长生', 月:'沐浴', 日:'冠带', 时:'临官' },       // 十二长生（自坐视角）
    整柱:       [ { pillar:'年', gan:'X', zhi:'Y', verdict:'截脚/天地同气/...' }, ... ]
  }
```

**常用取数**：
- 命局十神 → `bazi.shiShen`；喜忌依据 → `bazi.enrichment.旺衰.verdict` + `bazi.enrichment.格局`.
- 当前大运 → 在 `bazi.dayun` 中找 `startYear ≤ 当前年 ≤ endYear` 的项，读 `ganShiShen` / `zhiShiShen`.
- 当年流年 → 从当前大运的 `liuNian` 里找 `year === 当前年` 的项，读 `ganZhi`，推算十神与引动.
- 命局长期关系 → `bazi.enrichment.天干关系 / 地支关系`.

## 八、示例（通用演示数据，非真实用户）

- 命局：`siZhu` 年甲子 / 月丙寅 / 日戊辰 / 时庚午；`dayMaster` 戊；`shiShen` 年七杀/月偏印/日比肩/时食神；`格局` 正官格（confidence 高）；`旺衰` 偏弱（score <数值>）。
- 当前大运：找 `startYear ≤ 当前年 ≤ endYear` 的那一柱 → 读 `ganShiShen` / `zhiShiShen` 判断主旋律。
- 解读要点（示例）：
  - 日主偏弱 + 正官格 → 命局底色偏「框架 / 责任 / 名分」，外界加框架多，自身能量需「印比」支撑（学习、团队、靠山）。
  - 年干「七杀」→ 压力与攻坚的窗口，配合杀印相生思路，适合扛硬仗时借印（学习/贵人）化解。
  - 流年引动判断：取当年流年干支，看合冲刑害命局哪一柱、引动哪个十神，再给「今年适不适合做 X」的判断。
