## 一、易经 / 周易：时·位·中·正

### 时·位·中·正（核心方法论）
- **时**：时机与天时——这件事当下处在什么「时机」？（潜 / 现 / 跃 / 飞 / 亢）
- **位**：位置与处境——你站在什么位置？（底层起步 / 中层做事 / 高层守成 / 顶点防亢）
- **中**：中道，不偏不倚（二爻、五爻居中）——不走极端，抓平衡点。
- **正**：正位，名正言顺（爻位阴阳得正）——做名分正当、规则认可的事。

**决策用法**：判断任何决策，先答四问——①现在的时（早/正好/晚了）？②我的位（强/弱/内/外）？③我怎么保持中（不激进不保守）？④这事名分正不正？四问同向 → 可动；任一反向 → 缓。

### 爻辞的时机隐喻（乾卦六爻 = 人生/项目的六个阶段）

| 原文 | 出处 | 白话 | 决策用法 |
|------|------|------|---------|
| 初九：潜龙勿用 | 乾卦 | 龙潜伏在水下，时机未到，不宜施展 | 项目/身份尚未成熟时，别急着抛头露面、别硬上大场面，先蓄力 |
| 九二：见龙在田，利见大人 | 乾卦 | 龙出现在地面，宜拜见有德有位之人 | 小有进展时，主动去链接贵人、借力上位 |
| 九三：君子终日乾乾，夕惕若厉，无咎 | 乾卦 | 昼夜勤勉且时时警惕，才无灾祸 | 上升途中要既努力又警觉，居安思危 |
| 九四：或跃在渊，无咎 | 乾卦 | 或跃起或栖渊，进退试探都无咎 | 关键一跃前，允许试探、允许退一步再进 |
| 九五：飞龙在天，利见大人 | 乾卦 | 龙飞到天上，大展宏图，宜见贵人 | 时机已到、位置已正，全力推进、广结善缘 |
| 上九：亢龙有悔 | 乾卦 | 龙飞得太高，进退失据，必有悔 | 已在顶点/已极盛，别再加杠杆，及时知止、让位 |

**决策用法**：把当前决策对应到六爻阶段——「潜→现→跃→飞→亢」。多数人犹豫在「潜」该不该动；多数人吃亏在「亢」还要追。识别阶段，再决定攻守。

### 其它常用句

|------|------|------|---------|
| 穷则变，变则通，通则久 | 系辞下 | 走到尽头就会变，变了就通，通了才能长久 | 现有路径走到头 / 反复受挫时，果断换模式，别死磕 |

## 二、道德经：顺势 · 知止 · 波动平复

| 原文 | 出处 | 白话 | 决策用法 |
|------|------|------|---------|
| 人法地，地法天，天法道，道法自然 | 第25章 | 人效法地，地效法天，天效法道，道效法自然 | **顺势**——决策先看清大趋势，顺着环境规律走，别逆势硬刚 |
| 知足不辱，知止不殆，可以长久 | 第44章 | 知足就不会受辱，知止就不会有危险，可以长久 | **知止**——已经够好 / 已经足够时，主动停下，别贪多求满 |
| 飘风不终朝，骤雨不终日 | 第23章 | 狂风刮不了一整天，暴雨下不了一整天 | **波动终会平复**——坏情绪、坏行情、低谷期都不会永久，熬过去即平复 |
| 合抱之木，生于毫末；九层之台，起于累土；千里之行，始于足下 | 第64章 | 大树从细芽长起，高台从一筐土垒起，千里路从第一步走起 | **积累**——大目标拆成毫末起步，从当下最小一步开始做 |
| 上善若水。水善利万物而不争 | 第8章 | 最高的善像水，利益万物而不争 | **柔胜刚**——冲突中别硬碰，用低姿态和借势解决问题 |
| 天下之至柔，驰骋天下之至坚 | 第43章 | 天下最柔软的东西，能驾驭天下最坚硬的东西 | **迂回**——硬碰不行就绕道，柔韧策略往往穿透僵局 |
| 祸兮福之所倚，福兮祸之所伏 | 第58章 | 灾祸倚着福，福里藏着祸 | **辩证看**——别被单点结果定论；坏事里找转机，好事里防风险 |

**决策用法**：道德经适合「调整心态与节奏」。做决策时自问：我是在顺势（道法自然）还是逆势？要不要到此为止（知止）？眼前波动是终朝风雨还是会过去？

## 三、孙子兵法：先胜后战（13 篇全覆盖）

| 原文 | 出处 | 白话 | 决策用法 |
|------|------|------|---------|
| 兵者，国之大事，死生之地，存亡之道，不可不察也 | 始计篇 | 用兵是大事，关乎存亡，不可不慎重考察 | **重大决策先察**——大投入 / 高风险的选择，先充分调查再下注 |
| 兵贵胜，不贵久 | 作战篇 | 打仗贵在速胜，不在于持久 | **速战速决**——拖久了耗资源/耐心/现金流的事宜速决别恋战；速决的前提是已「先胜」，别为快而准备不足 |
| 知彼知己，百战不殆 | 谋攻篇 | 既了解自己又了解对方，打一百次也不会危险 | **知己知彼**——决策前把「我有什么、对手/环境要什么、规则是什么」摸清 |
| 不战而屈人之兵，善之善者也 | 谋攻篇 | 不用打就让人降服，是最高明的 | **不战而胜**——优先用谈判、联盟、影响力解决，别一上来就开战（硬刚） |
| 上兵伐谋，其次伐交，其次伐兵，其下攻城 | 谋攻篇 | 最好的用兵是斗智谋，其次斗外交，再次斗武力，最下是硬攻城 | **先谋后力**——按「谋→交→兵→攻」降级解决问题：先动脑子、再谈合作、最后才硬拼，硬拼是下策 |
| 胜兵先胜而后求战，败兵先战而后求胜 | 军形篇 | 打胜仗的先创造必胜条件再开打；打败仗的先打了再盼赢 | **先胜后战**——动手前先把胜算做出来（资源、能力、退路），别抱着「先干了再说」 |
| 昔之善战者，先为不可胜，以待敌之可胜 | 军形篇 | 会打仗的先让自己立于不败之地，再等可胜之机 | **先为不可胜**——先保证「输了也不伤根本」（底线、退路、现金流），再谈赢 |
| 势如彍弩，节如发机 | 兵势篇 | 气势像拉满的弓弩，节奏像扣动扳机 | **蓄足再发**——机会窗口里蓄力要够、出手要干脆，别犹豫拖沓；借风口出手事半功倍 |
| 善战者，致人而不致于人 | 虚实篇 | 会打仗的人调动别人，不被别人调动 | **掌握主动**——别被对方节奏带着走，把主动权握在自己手里 |
| 避实而击虚 | 虚实篇 | 避开坚实处，攻打虚弱处 | **避实击虚**——别在对方强项上硬刚，找弱项/空白/需求缺口切入（竞争、选赛道、谈客户都适用） |
| 以迂为直，以患为利 | 军争篇 | 把迂回当直路，把祸患化为有利 | **迂回取胜**——看似绕远的路可能是捷径；把劣势/麻烦转成筹码（借力、错位竞争） |
| 智者之虑，必杂于利害 | 九变篇 | 聪明人考虑事情，一定兼顾利与害 | **兼看利害**——做决定别只看利或只看害：把利里藏的风险、害里藏的机会都列出来再动 |
| 令之以文，齐之以武 | 行军篇 | 用仁德教化，用法纪整肃 | **恩威并施**——带团队/合作光讲感情会散、光靠规矩会怨；人情与契约并用 |
| 知彼知己，胜乃不殆 | 地形篇 | 了解对方又了解自己，胜利就没有危险 | **赢得稳**——与「百战不殆」同义，但强调「赢下来也不危险」，适合求胜更求稳的场景 |
| 投之亡地然后存，陷之死地然后生 | 九地篇 | 把部队投入绝境，反而能存活 | **背水一战**——退路太多会让人分心时，斩断退路激发专注；只适用于「必须赢且有能力赢」的场合，须配「先为不可胜」慎用 |
| 主不可以怒而兴师，将不可以愠而致战 | 火攻篇 | 国君不能因愤怒发兵，将领不能因恼怒开战 | **情绪不上头**——情绪激动时别做重大决定（辞职/分手/签约/翻脸），先冷静过夜再动 |
| 明君贤将，所以动而胜人，成功出于众者，先知也 | 用间篇 | 贤明的将领一动就取胜，是因为事先掌握情报 | **赢在情报**——动手前把「情报」做足：调研、摸对方底牌、验需求；信息优势就是胜势 |

**决策用法**：孙子兵法适合「要不要抢、怎么抢、怎么赢」。任何竞争/取舍决策先过四道关：①我是不是「先胜而后求战」？（胜算已具再出手）②我有没有「先为不可胜」？（退路与底线）③我「知彼知己」了吗？（信息充分性）④我「杂于利害」了吗？（利与害都看全）。情绪上头时先停（火攻篇）。四关不过，就别急着动手。

## 四、决策调用总则

1. **看时** → 易经（乾卦六爻定位 + 时位中正）。
2. **看势与心态** → 道德经（顺势 / 知止 / 波动平复）。
3. **看竞争与胜算** → 孙子兵法（先胜后战 / 先为不可胜 / 避实击虚 / 杂于利害）。
4. **输出时给原文 + 白话**，再落到用户的现实行动，别只贴古文。
