# 天命顾问（tianming-advisor）

> 个人决策咨询 Claude Code Skill — 八字十神 + 大运流年 + 西洋星盘 + 健壮性认知系统 + 国学框架

当你想评估一个决定（该不该做 X / 现在适不适合 / 这个方向对不对 / 时机判断）时，skill 综合命理时机、个人方法论、人格档案三条线，输出结构化参考建议。

**注意：非娱乐算命。** 定位是「命理时机 + 方法论 + 人格」的决策参考工具，不替代医疗、法律等专业意见（输出自带免责声明）。

## 触发与不触发

| 触发（决策类问题） | 不触发 |
|---|---|
| 该不该做 X / 现在适不适合 / 这个方向对不对 / 时机判断 | 纯星座娱乐（运势、配不配） |
| 想结合八字、星盘、国学评估一个决定 | 严肃医疗、法律等专业建议 |
| | 不含「决策」成分的纯命理好奇 |

## 需要的输入

1. **你的决策问题**：是什么决定、在犹豫什么、有没有时间限制。
2. **出生信息已内置**在 `config.yaml`，首次使用时让用户复核一遍（出生日期/时辰/地点）确认无误。

## 决策管线

全是确定性计算，不靠 LLM 猜：

```
① 读 config.yaml 基线（出生信息/人格档案）→ 顺带识别判断偏差（哪些犹豫是事实、哪些是内耗噪音）
   ├─ scripts/chart.js  → 八字排盘（四柱/十神/大运流年/格局旺衰）
   └─ scripts/astro.js   → 西洋星盘（太阳/月亮/上升）
        ↓
references/ 六份解读规则（shishen / dayun-liunian / jianzhuang / guoxue / xingzuo / wuxing-buyi）
        ↓
SKILL.md 编排五段式输出（①时机 ②自身匹配 ③风险 ④建议+国学原文 ⑤三检验 + 免责）
```

## 输出格式（五段 + 免责）

| 段 | 内容 | 回答的问题 |
|---|---|---|
| ① 时机结论 | 当前大运主题 + 流年引动哪个十神 | 现在宜动/宜蓄/宜等？顺势还是逆势 |
| ② 自身匹配度 | 十神视角 + 人格视角 + 星盘三方镜 | 这事落不落在你的天性和驱动上 |
| ③ 风险点 | 健壮性认知系统拆解（根/叶、过拟合/健壮） | 动的是基本盘还是短期信号？缺什么 |
| ④ 决策建议 | 国学框架带一句原文 + **可做的第一步** | 到底怎么走？先动哪根叶 |
| ⑤ 三检验 | 通（可迁移）/ 简（砍到骨架）/ 活（冲击下站得住） | 这建议经得起推敲吗 |
| 免责 | 命理为传统文化参考，非科学依据 | 重大决定请理性判断 + 专业意见 |

## 安装

1. 克隆本仓库：`git clone https://github.com/NI9N/tianming-advisor.git`
2. 补一份 `config.yaml`（出生日期/时辰/地点/人格基线，见下方「隐私」说明）
3. 运行 `.\install.ps1`：
   - `npm install`（astronomia + js-yaml）
   - 自动克隆排盘引擎 `bazi-ziwei-skill`（MIT）到 `engine/`
   - 部署到 `~/.claude/skills/tianming-advisor/`

安装后，在新会话里说「用天命顾问看看该不该…」即可触发。

## 隐私

`config.yaml` 包含个人出生信息（日期/时辰/地点）和人格档案，已被 `.gitignore` 排除，**不进任何 git 仓库**，仅本地保留供 skill 运行。重装/迁移需手动补这份文件。

## 依赖

- [astronomia](https://www.npmjs.com/package/astronomia) ^4.2.0 — 西洋占星计算
- js-yaml ^4.1.0 — 读取 config.yaml
- [bazi-ziwei-skill](https://github.com/dzcmemory-web/bazi-ziwei-skill)（MIT）— 八字排盘引擎，安装时克隆到 `engine/`，不入库

## 时辰边界

八字排盘用钟表时间（引擎默认，不做真太阳时校正）。出生地经度来自 `config.yaml`，真太阳时相对钟表时的偏移由出生地经度决定。默认跟随引擎用钟表时；是否启用真太阳时校正见 SKILL.md「时辰边界说明」。

## 和模板算命差在哪

1. **读的是「你的」东西**：出生信息 + 人格档案 + 你自己那套方法论（健壮性认知系统），不是通用命理模板。
2. **配置开放**：人格基线（`config.yaml`）可改；方法论规则（`references/jianzhuang.md`）可换成你自己的系统。
3. **隐私**：`config.yaml` 被 `.gitignore` 排除，不进任何 git 仓库，只存本地。
4. **确定性计算**：排盘不靠 LLM 猜，两次运行结果一致。

## 局限

- 它**不指路**——信息得你诚实、详细地给，它才帮得上。
- 它是**理清思路的工具**，最后的决定权在你手上。
- 命理是传统文化参考，**非科学依据**；不替代医疗、法律等专业意见。

## 示例输出（虚构演示数据）

> 以下为**虚构用户**（出生 1990-07-20 09:30 北京，男）对问题「该不该辞掉稳定的工作，转去做自由职业」的真实引擎输出演示。非真实用户，不包含任何个人数据。

**排盘结果（脚本确定性计算）**

```
八字四柱  庚午 / 癸未 / 丙戌 / 癸巳（日主 丙）
十神      年偏财 / 月正官 / 日比肩 / 时正官
格局      伤官格（中）        旺衰  中和（score -0.8）
调候用神  壬、庚              五行  火最旺（3.8），缺木（印）
当前大运  丁亥（劫财/七杀）37-46 岁   流年 2026 丙午
地支关系  三会火方（午未巳）/ 午未六合 / 未戌相刑 / 拱合火局
星盘      太阳巨蟹 27° / 月亮双子 29° / 上升处女 19°
```

**五段式建议（skill 编排输出）**

**① 时机结论** — 大运「劫财+七杀」是攻坚、竞争、施压的十年；流年火旺身由中和转强，动能足、宜开拓。但双正官透干 + 七杀大运 = 环境在施压、要你扛硬仗。结论：**宜动，但宜「先备而后动」，不是裸奔的时机。**

**② 自身匹配度** — 伤官格配双正官：有创造力、又习惯待在规则里，转自由职业正是内在拉扯点；太阳巨蟹想安稳、月亮双子想变化，是「想动又怕动」；上升处女，外人看你是严谨靠谱的细节控（转自由职业是加分项），但自己容易因「没做到完美」卡住。

**③ 风险点**（依据你的健壮性认知系统）— 辞职动的是**根**（收入基本盘）；如果方向没验证过客户和现金流，就是把**叶**（对现状不满）当成了**根**。缺：**退路**（缓冲资金）+ **验证**（客户来源）。因一时受挫想走是过拟合；健壮路径是「在稳的框架里先测新的」。

**④ 决策建议** — 「先为不可胜，以待敌之可胜」（《孙子兵法·军形篇》）「胜兵先胜而后求战」。时机动能足但缺退路和验证，**现在不宜裸辞**。可做的第一步：留在现职的同时接一个付费小单，走通「客户→报价→交付→收款」闭环，攒出 3-6 个月缓冲再决定是否全押。

**⑤ 三检验自检** — 通：可迁移到任何转型决定；简：核心一句「先小步验证、别裸辞赌」；活：就算不成，有退路、有积累，站得住。

> 免责声明：以上为虚构示例。命理为传统文化参考，非科学依据；重大决定请结合理性判断与专业意见。
